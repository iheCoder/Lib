# ChatGPT New Tab

一个轻量的 Chrome 扩展：每次打开新标签页时直接进入官方
[ChatGPT](https://chatgpt.com/) 首页，并可用本地图片定制页面背景。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions/`。
2. 打开右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择本目录 `plugins/chrome_new_tab/`。
5. 如果 Chrome 提示多个扩展都想控制新标签页，请保留启用本扩展。

安装后新建一个标签页即可验证。ChatGPT 会沿用浏览器中已有的登录状态。

## 设置背景

1. 把扩展固定到 Chrome 工具栏，然后点击扩展图标。
2. 选择 PNG、JPEG、WebP 或 AVIF 图片。
3. 按需调整填充方式、暗色遮罩、背景模糊和面板不透明度。

背景以 ChatGPT 的主对话区域为边界，不会延伸到侧边栏。「对话区完整显示」会把
整张照片居中放入对话区域；侧边栏展开、收起和窗口尺寸变化时，背景边界会自动
重新计算。

设置会立即同步到已打开的 ChatGPT 标签页。开关可以暂时停用背景，「移除图片」
会清除本地图片并恢复官网样式。大图会在浏览器内缩放并转成 WebP，原始文件不会
被上传或修改。

## 设计说明

ChatGPT 的安全策略不允许第三方页面通过 iframe 嵌入，因此扩展会从本地新
标签页立即跳转到 `https://chatgpt.com/`。这可以完整保留官网功能，也避免扩展
接触账号、对话或浏览记录。

为了修改 ChatGPT 的页面背景，扩展只申请 `storage` 权限，并且内容脚本严格限制
在 `https://chatgpt.com/*`。背景和显示设置保存在 `chrome.storage.local`，不会
上传、同步或发送给第三方。扩展不读取对话内容，也不包含后台服务。

ChatGPT 偶尔会调整页面结构。本扩展只覆盖较稳定的页面表面样式；未识别的新组件
会保持官网原样，避免样式适配失败影响对话功能。
