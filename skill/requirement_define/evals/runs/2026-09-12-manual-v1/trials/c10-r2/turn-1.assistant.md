**线下活动自主报名与取消**

**背景与目标**

为线下活动提供用户自主报名、取消报名的能力，减少工作人员手工登记，确保报名人数不超过活动名额，重复操作不会多占名额。

**报名规则**

- 活动开始前，已登录用户可以为自己报名。
- 每名用户在每场活动中最多有一份有效报名；每份有效报名占用一个名额。
- 名额用完时不能报名。
- 已有有效报名的用户重复报名，不新增有效报名，也不额外占用名额。
- 活动开始后不能再报名。

**取消与重新报名规则**

- 用户仅可在活动开始前取消自己的有效报名。
- 取消成功后，该报名不再有效，并立即释放对应名额。
- 没有有效报名时不能取消；重复取消不能再次释放名额。
- 取消后，若活动尚未开始且仍有名额，用户可以重新报名；原名额不为该用户保留。
- 活动开始后不能取消报名。

**结果一致性与重要场景**

报名或取消失败时，原报名和剩余名额保持不变。多人同时操作或同一用户重复操作，也必须满足上述规则。

| 场景 | 预期结果 |
|---|---|
| 活动未开始，用户无有效报名且有名额 | 报名成功，产生一份有效报名，占用一个名额 |
| 用户已有有效报名，再次报名 | 保持原有效报名，不额外占用名额 |
| 多人同时争取最后一个名额 | 最多一人报名成功，不超额 |
| 用户在活动开始前取消有效报名 | 报名失效，立即释放一个名额 |
| 用户无有效报名或重复取消 | 不能取消，不释放名额 |
| 用户取消后，名额已被其他用户占满 | 不能重新报名 |
| 报名或取消失败 | 该次操作不改变报名及名额 |
| 活动已开始 | 不能报名，也不能取消 |

上述“不改变”指失败操作本身不产生变更，不妨碍其他用户成功操作引起名额变化。

**现有规则与范围边界**

- 活动开始时间使用现有产品提供的值，是否开始沿用现有时间规则；本次不修改时间规则，也不支持活动开始时间变更。
- 本次不做候补、支付、代报名或通知。
- 管理员目前没有代用户取消的入口，本次不新增该能力。

具体页面布局、操作提示文案可在后续交互设计中确定，不影响以上业务规则。
