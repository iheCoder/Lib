本次需求为：**首页默认列表隐藏归档项目，其他入口、访问权限和归档规则保持不变。**

背景与目标：当前首页默认列表同时展示未归档和归档项目，影响用户寻找正在推进的项目。调整后，用户进入首页默认列表时，只看到原有可见范围内的未归档项目。

具体业务规则：

| 场景 | 预期行为 |
|---|---|
| 首页默认列表 | 不展示归档项目；未归档项目的原有展示规则不变 |
| 已有“归档项目”筛选入口 | 保持现有行为，用户仍可通过该入口查找归档项目 |
| 历史报表进入归档项目详情 | 保持现有行为，按原有权限访问 |
| 通过收藏的详情地址直接访问 | 保持现有行为，按原有权限访问 |
| 归档项目内容 | 仍不可编辑；有原查看权限的用户仍可查阅 |
| 项目访问权限 | 归档及本次展示调整均不改变权限，不扩大或收回访问范围 |

调整适用于已有和后续归档的项目。项目归档后，不再出现在首页默认列表中，但仍可通过上述已有入口查阅。

验收时应确认：

- 用户原本可见的项目中，若同时存在未归档和归档项目，首页默认列表仅展示未归档项目。
- 若用户原本可见的项目全部已归档，首页默认列表不展示这些项目。
- 归档项目仍可通过归档筛选、历史报表和收藏地址访问，结果符合原有权限规则。
- 有查看权限的用户仍可查阅归档内容，但不可编辑；无查看权限的用户不会因本次调整获得访问权限。

本次不修改归档条件，不涉及删除、恢复、保留期限或新的权限体系，也不调整首页默认列表之外的归档项目展示行为。
