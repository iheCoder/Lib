**线下活动自助报名与取消需求**

为线下活动增加用户自助报名、取消及管理员取消报名能力，减少工作人员手工登记。

**用户报名**

- 活动开始前，已登录用户可以在仍有名额时为自己报名。
- 每人每场活动最多有一份有效报名，每份有效报名占用一个名额。重复报名不能新增有效报名或额外占用名额。
- 名额用完或活动开始后，不能报名。
- 用户取消后可以重新报名，但须重新满足活动未开始且仍有名额的条件；取消不保留名额。

**取消报名**

| 操作者 | 可取消的报名 | 时间限制 |
|---|---|---|
| 用户本人 | 自己的有效报名 | 仅限活动开始前 |
| 当前活动的管理员 | 本活动中任意用户的有效报名，无需用户再次确认 | 仅限活动开始前 |
| 非当前活动的管理员 | 无权以管理员身份取消本活动报名 | — |

- 取消成功后，该报名不再有效，并立即释放一个名额。
- 没有有效报名时不能取消；重复取消不能额外释放名额。
- 活动开始后，用户本人和当前活动的管理员均不能取消报名。

**一致性与主要验收场景**

报名成功与占用名额、取消成功与释放名额必须保持一致。报名或取消失败时，该次操作不得改变原报名和剩余名额；其他成功操作仍可正常改变剩余名额。

| 场景 | 预期结果 |
|---|---|
| 已登录用户无有效报名，活动未开始且有名额 | 报名成功，占用一个名额 |
| 同一用户重复或同时提交报名 | 最多形成一份有效报名，最多占用一个名额 |
| 多人同时争取最后一个名额 | 最多一人报名成功，不得超额报名 |
| 名额已满或活动已开始时尝试报名 | 不能新增报名 |
| 活动开始前，用户本人或本活动管理员取消有效报名 | 取消成功，立即释放一个名额 |
| 用户和管理员同时取消同一份有效报名 | 最终报名无效，只释放一个名额 |
| 没有有效报名时尝试取消 | 不能取消，不释放名额 |
| 非本活动管理员尝试代用户取消 | 操作失败，报名和名额不变 |
| 活动开始后，用户或管理员尝试取消 | 操作失败，报名和名额不变 |
| 报名被本人或管理员取消后，用户重新报名 | 按相同报名条件重新判断，满足条件即可成功 |

**现有规则与范围**

活动开始时间及时间判定规则沿用现有产品，本次不修改时间规则，也不支持活动开始时间变更。

本次不做候补、支付、代报名或通知。管理员取消报名属于本次范围，但不扩展为管理员代用户报名。
