**线下活动自助报名需求**

为线下活动增加用户自助报名和取消能力，减少工作人员手工登记。用户只能操作自己的报名。

**报名规则**

- 活动开始前，已登录用户在仍有名额时可以为自己报名。
- 每人每场活动最多有一份有效报名，每份有效报名占用一个名额。
- 已有有效报名时，重复报名不得新增有效报名或额外占用名额。
- 名额用完后不能报名；活动开始后不能报名。

**取消与重新报名**

- 用户只能在活动开始前取消自己的有效报名；活动开始后不能取消。
- 取消成功后，该报名不再有效，并立即释放一个名额。
- 没有有效报名时不能取消，不能因此释放名额。
- 取消后，若活动尚未开始且仍有名额，用户可以重新报名。取消不保留原名额，重新报名遵循相同的报名规则。

**结果一致性与重要场景**

报名和名额变化必须保持一致：报名成功才占用名额，取消成功才释放名额。报名或取消失败时，该次操作不得改变原报名和剩余名额；其他用户的成功操作仍可正常改变剩余名额。

以下场景应作为主要验收依据：

| 场景 | 预期结果 |
|---|---|
| 已登录用户无有效报名，活动未开始且有名额 | 报名成功，形成一份有效报名，剩余名额减少一个 |
| 同一用户重复或同时提交多次报名 | 最多形成一份有效报名，最多占用一个名额 |
| 多人同时争取最后一个名额 | 最多一人报名成功，不得超额报名 |
| 活动名额已满或活动已开始 | 不能新增报名 |
| 活动未开始，用户取消自己的有效报名 | 取消成功，立即释放一个名额 |
| 无有效报名，或重复取消已取消的报名 | 不能取消，不得额外释放名额 |
| 活动已开始，用户尝试取消 | 不能取消，原报名和名额不变 |
| 取消后重新报名 | 重新判断是否未开始且有名额，满足条件才可成功 |
| 报名或取消失败 | 该次操作不改变原报名和剩余名额 |

活动是否已经开始，沿用现有产品提供的开始时间及时间判定规则，本次不重新定义时间边界。

**范围边界**

本次不包含候补、支付、代报名、通知或管理员代用户取消入口；不修改现有时间规则，也不支持活动开始时间变更。
