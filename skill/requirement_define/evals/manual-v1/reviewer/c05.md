# c05：成员导出：冲突解决后收敛

仅供主持人和评判者阅读，不发给被测 Agent。通用流程见 ../README.md，通用评分见 rubric.md。

## 检查点与可接受结果

第一轮同 c04。保存结果后发送 turn-2.md，不论它是否问对问题；第一轮的错误不会被后续修正抹去。
第二轮：以管理员权限为准形成完整需求，不再残留冲突或普通成员成功导出的说法；不要求用户再说“生成文档”。

## 明确失败

第二轮继续追问材料优先级；正文与例外规则的权限矛盾；只答“收到，以业务说明为准”而不交付文档。第一轮静默裁决也单独记失败。

## 用户应答

第一轮结束后原样发送 turn-2.md。不要添加“现在请输出最终文档”，否则无法测试自动收敛。

## 文档独立阅读检查

只给另一个读者最终文档，不给对话和本页；请其回答下列问题。主持人用括号内的参考判断，不能把参考一同发给读者。

- 普通成员能导出吗？（不能。）
- 可以跨团队导出吗？（不能。）
- 空列表和导出失败分别怎样？（仅表头；提示失败且不提供不完整文件。）
