# c07：归档项目：范围清楚

仅供主持人和评判者阅读，不发给被测 Agent。通用流程见 ../README.md，通用评分见 rubric.md。

## 检查点与可接受结果

第一轮直接输出需求，表达只改变默认列表且相关入口、权限不变。无需强制逐句重复原文，只要不会产生不同业务结果。

## 明确失败

重复追问报表能否访问；要求先制定删除或保留规则；遗漏访问约束导致文档可被合理解释成全面禁用。

## 用户应答

没有预设的后续业务决定。按通用应答规则处理额外问题，不能临场补造规则。

## 文档独立阅读检查

只给另一个读者最终文档，不给对话和本页；请其回答下列问题。主持人用括号内的参考判断，不能把参考一同发给读者。

- 从哪个入口隐藏？（首页默认列表。）
- 归档项目能编辑吗？（仍不能。）
- 已有报表入口能继续查阅吗？（有原权限时可以。）
