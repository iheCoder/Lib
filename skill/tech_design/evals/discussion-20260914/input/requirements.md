本文件是根据两个交互原型、既有需求稿及本轮确认结果收敛后的业务需求。原型用于说明页面布局和交互意图；原型与本文件冲突时，以本文件为准。

本文将后台维护的内容称为“组织模板”，将用户本人维护的内容称为“个人模板”。首页可以继续使用更易理解的“指令”作为展示文案。

## 2. 背景与目标

用户进入超级助手新建任务页后，面对空白输入框往往不知道系统能够完成哪些工作，也不知道应该如何组织提示词、补充材料或选择相关能力。

本次需求希望达到以下目标：

1. 用户进入首页后，可以直接发现并使用适合自己的任务模板。
2. 租户管理员可以持续维护组织模板及其分类、提示词、可见范围、Skill 和知识库。
3. 用户可以收藏组织模板、查看本人常用模板，并创建仅本人可见的个人模板。
4. 模板只负责任务内容和资源组合，不改变 Skill、知识库原有的权限规则。
5. 管理员可以通过近 30 天的使用和收藏数据判断组织模板的实际价值。

## 3. 本期范围

本期包含：

- 首页组织模板分类与推荐展示；
- “全部”“常用”“收藏”“我的”四个固定入口；
- 组织模板和个人模板的查看、补充信息、填入输入框及执行；
- 用户收藏、取消收藏；
- 用户查询和修改仅影响本人的“常用”规则；
- 用户创建、编辑和删除个人模板；
- 管理后台的分类管理、组织模板管理、排序、启停和可见范围管理；
- 组织模板和个人模板绑定多个 Skill、多个知识库；
- 管理后台的使用统计及收藏排行榜。

本期不包含：

- “猜你要用”及任何基于历史对话自动生成模板的能力；
- 分类级可见范围；
- 分类启用、停用；
- 按指定个人设置模板可见范围；
- 将个人模板发布或分享给其他用户；
- 通过模板向用户授予 Skill 或知识库权限；
- 因用户缺少 Skill 或知识库权限而提前隐藏模板。

## 4. 用户与权限边界

### 4.1 普通用户

普通用户可以：

- 查看命中本人可见范围的组织模板；
- 查看、使用和管理本人的个人模板；
- 收藏或取消收藏可见模板；
- 使用“全部”“常用”“收藏”“我的”入口；
- 在执行模板前补充参数、编辑最终输入内容和附件。

普通用户不能进入管理后台，也不能查看或修改其他用户的个人模板。

### 4.2 租户管理员

租户管理员可以管理当前租户的分类和组织模板，包括新增、编辑、删除、排序、模板启停、模板可见范围、Skill 绑定和知识库绑定。

管理员创建或编辑组织模板时，可选择本人当前能够看到的：

- 全局内置 Skill；
- 当前企业的 Skill；
- 管理员本人的个人 Skill；
- 全部可见知识库。

管理员能看见某个 Skill 或知识库，只代表可以将它绑定到模板，不代表其他用户同时取得该资源的使用权限。

## 5. 首页模板浏览

### 5.1 首页结构

首页保留原有任务输入框，并在输入框上方展示模板区域。固定入口依次为：

1. 全部；
2. 常用；
3. 收藏；
4. 我的；
5. 管理员维护的业务分类。

“猜你要用”不展示。

业务分类只用于组织模板归类。首页分类导航返回全部未删除业务分类，不计算模板数量；即使分类为空或当前用户看不到其中模板也正常展示，切换后模板列表可以为空。

### 5.2 各入口内容

- **全部**：展示当前用户可见的组织模板和本人个人模板。组织模板按分类和后台排序展示，个人模板在组织模板之后展示。
- **常用**：展示本人在统计窗口内实际反复使用、且当前仍可见的组织模板和个人模板。具体进入门槛沿用现有需求中的默认规则。
- **收藏**：展示本人当前收藏且查询时仍有效的模板，按最近收藏时间倒序排列；已删除、已停用或当前用户不再可见的模板不返回。
- **我的**：只展示本人创建的个人模板，并提供创建入口。
- **业务分类**：展示该分类下当前用户可见且已启用的组织模板。

### 5.3 模板卡片与详情

模板卡片至少展示名称、描述、来源标识和收藏入口，可以展示图标及所属分类。

用户可以进入模板详情查看完整提示词、待填参数、所绑定的 Skill 和知识库，并选择使用模板。

如果系统能够判断某个已绑定资源已经无权限、被停用或被删除，应在资源绑定项或模板详情中显示相应的不可用状态，帮助用户理解可能的执行结果。资源失效提示不改变模板自身的可见和启用状态。

## 6. 模板使用流程

1. 用户点击模板。
2. 没有待填参数时，将模板内容填入任务输入框；存在参数时，先要求用户补充参数。
3. 用户可以继续修改生成的输入内容、添加或删除附件，并增删模板预置的 Skill 和知识库。
4. 如果输入框中已有内容，替换前必须征得用户确认，不能静默覆盖。
5. 用户确认后发送任务，任务关联本次使用的模板及其当时版本。

点击模板、查看详情、补充参数或填入输入框都不等于已经执行。只有任务提交被系统接受后，才记为一次模板使用。

### 6.1 Skill 和知识库权限

模板可见范围与绑定资源的使用权限相互独立：

- 用户只要命中模板可见范围，就可以看到、收藏、打开和发送该模板；
- 模板绑定 Skill 或知识库不会向用户授予相应权限；
- 用户无权使用绑定资源时，不在模板列表阶段拦截或隐藏模板；
- 模板绑定的 Skill 和知识库只是填入任务时的默认资源，用户发送前可以增加或删除；发送时以用户最终选择的完整资源列表为准，服务端不能把已被用户删除的模板资源重新合并回来；
- Skill 继续进入现有执行链，当前不可执行的 Skill 沿用现有静默剔除行为；
- 知识库继续使用当前用户身份调用 RAG。权限不足、资源删除或停用时，不调用大模型，由会话服务生成明确的助手消息并写入对话历史；不能向前端暴露内部错误；
- RAG 超时或服务不可用等系统故障与资源权限问题分开提示，不能把系统故障错误描述成用户没有权限。

因此，模板任务可能已经成功提交，但随后因某个最终保留的资源不可用而执行失败。这种情况仍按“已提交使用”计入使用次数，但不能记为任务成功。

只要用户没有主动解除模板关联，后续每次有效发送都继续携带模板 ID，并分别计为一次模板使用。每次新的发送生成新的模板提交幂等 ID；同一次 HTTP 重试复用原 ID，断点续流和重新生成不重复计数。

## 7. 可见范围

分类不配置可见范围。组织模板单独配置自己的可见范围。

模板可见范围支持：

- 组织全员；
- 指定范围。

指定范围可以同时选择：

- 一个或多个部门；
- 一个或多个人员标签。

同一模板选择的部门和人员标签按并集计算。用户命中任意一个已选部门，或者命中任意一个已选人员标签，即可看到模板。

选择某个部门时，包含该部门本身以及它下面所有层级子部门的人员。

指定范围至少需要选择一个部门或一个人员标签。本期不支持直接选择具体人员。

模板可见还需同时满足：模板属于当前租户、未删除并处于启用状态。Skill 和知识库权限不参与模板可见性计算。

## 8. 分类管理

分类只负责组织模板的归类和首页展示顺序。

管理员可以：

- 新增分类；
- 编辑分类名称、描述和图标；
- 调整分类顺序；
- 删除空分类。

分类不配置可见范围，也不设置启用或停用状态。

一个组织模板只能属于一个分类。分类下仍有未删除模板时不能删除，需要先将模板移动到其他分类或删除模板。分类和模板删除均采用软删除，用户端和管理端普通查询只返回未删除记录。

分类名称在当前租户内不能重复。“全部”“常用”“收藏”“我的”等固定入口名称不能作为业务分类名称。

## 9. 组织模板管理

### 9.1 模板内容

组织模板至少包含：

- 名称；
- 描述；
- 所属分类；
- 提示词；
- 待填参数；
- 图标；
- 可见范围；
- 绑定的 Skill；
- 绑定的知识库；
- 启用或停用状态。

新建组织模板默认停用。管理员完成内容和范围检查后可以启用；停用后，模板从所有用户入口中停止提供，但历史任务和统计仍保留。

### 9.2 参数

模板可以通过占位符声明需要用户补充的信息。参数支持单行文本、多行文本和枚举选择。参数定义必须与提示词中的占位符一致，缺少必填值时不能填入或发送。

### 9.3 Skill 与知识库绑定

单个模板允许同时绑定多个 Skill 和多个知识库。本期 Skill 最多绑定 50 个，知识库最多绑定 50 个，两类资源分别计数。

新绑定资源只能从当前编辑者有权看到的资源中选择。

已绑定资源后来出现以下变化时，不自动解除绑定，也不自动停用或隐藏模板：

- 被删除；
- 被停用；
- 当前模板管理员失去查看或使用权限；
- 最终使用模板的普通用户没有使用权限。

当系统能够识别失效原因时，管理页面应保留该绑定项并标记“无权限”“已停用”或“已删除”等状态，管理员可以据此移除或替换资源。不能因为资源已经不可见，就在编辑保存时静默删除原绑定。

### 9.4 编辑、移动和删除

- 编辑已启用模板并保存后，新内容对后续使用生效；已经开始的任务仍使用启动时的内容。
- 模板移动到其他分类后，保留原模板身份、收藏关系和使用统计。
- 模板必须先停用再删除。
- 删除后不再出现在首页；历史任务和统计仍需保留可识别的模板引用。
- 已填入但尚未发送的模板若发生内容变更，应保留用户草稿并提示重新确认，不能静默替换。

## 10. 个人模板“我的”

个人模板由用户本人创建，只对创建者可见。

用户可以：

- 从“我的”入口创建个人模板；
- 从组织模板内容开始自定义并另存为个人模板；
- 编辑或删除本人个人模板；
- 收藏本人个人模板；
- 在“全部”“常用”“收藏”“我的”中使用符合相应规则的个人模板。

个人模板的提示词、参数、Skill 和知识库绑定能力与组织模板一致，但存在以下区别：

- 不属于组织业务分类；
- 不配置部门或人员标签范围，固定仅本人可见；
- 不提供发布、分享或转为组织模板的入口；
- 管理员不能查看或编辑其他用户的个人模板；
- Skill 和知识库只能从当前用户本人能够看到的资源中选择；
- 绑定资源失效后，个人模板仍保留，详情或编辑页面显示失效状态，执行时按原有权限失败。

“另存为我的”复制源组织模板的全部 Skill 和知识库绑定，包括当前用户无权使用或当前已经失效的资源。复制操作不因这些资源不可用而丢弃或拒绝；模板详情及复制结果同时返回各资源当前是否可用及能够识别的失效原因，供界面提前提醒。复制完成后的个人模板与源组织模板相互独立，后续不自动同步。

单个个人模板绑定 Skill 与知识库的数量限制与组织模板相同：Skill 最多绑定 50 个，知识库最多绑定 50 个，两类资源分别计数。

取消收藏不会删除个人模板。用户明确删除个人模板后，它才从“我的”、收藏和常用入口中失效。

## 11. 收藏

用户可以在模板卡片和详情中收藏或取消收藏。收藏操作只创建用户与模板之间的关系，不复制组织模板内容。

组织模板更新后，收藏仍指向该模板的当前版本。模板停用、删除或者用户不再命中模板可见范围时，用户不能通过旧收藏继续查看其内容或执行，收藏列表不返回该模板，也不返回任何失效占位。

收藏入口展示的数量与收藏列表使用同一有效性口径，只统计查询时未删除、已启用且当前用户仍可见的收藏模板。模板暂时停用或用户暂时失去可见范围时可以保留底层收藏关系，恢复有效后重新出现在收藏列表和数量中；模板删除时可以清理对应收藏关系。

绑定 Skill 或知识库失效不使收藏关系失效，因为模板本身仍保持可见和启用。

## 12. 常用

“常用”根据用户本人实际提交模板任务的记录自动形成，不由管理员手工指定，也不以收藏或卡片点击代替使用。

用户可以在个人设置中查询和修改仅影响本人的常用规则：统计窗口默认 30 天、允许 7～90 天；最少使用次数默认 3 次、允许 2～20 次；最多展示条数默认 20 条、允许 6～50 条。覆盖至少 2 个自然日为本期固定规则，不提供用户修改。用户没有保存过个人设置时使用默认值。

组织模板和个人模板分别按各自稳定身份累计，同一模板从不同入口提交时合并统计。个人常用规则修改后，后续查询按最新设置重新计算，不改变历史使用记录，也不影响其他用户。个人常用规则记录同样采用软删除；被删除的设置按“未配置”处理并回退默认值。

模板当前不可见、已停用或已删除时，不出现在常用列表。因 Skill 或知识库权限问题在任务提交后执行失败的，仍属于一次已提交使用。

## 13. 管理统计与收藏排行榜

管理统计只展示当前租户的组织模板，不展示个人模板内容或个人模板排名。

### 13.1 使用统计

管理员可以查看近 7 天或近 30 天的组织模板使用次数、使用人数和使用趋势。任务被系统接受才计为使用，查看、收藏和填入输入框均不计入使用次数。

### 13.2 收藏排行榜

收藏排行榜默认返回最近 30 天的前 10 个组织模板。

排行规则为：

1. 统计最近 30 天内收藏过该组织模板、当前仍保持收藏、模板当前已启用且未删除，并且收藏用户仍命中模板可见范围的去重用户数；
2. 同一用户对同一模板最多计 1 人；
3. 用户取消收藏后，不再计入该模板排行；
4. 用户取消后又重新收藏，在最近 30 天窗口内仍只计 1 人；
5. 按去重收藏用户数从高到低排名，默认展示 Top 10；
6. 个人模板不参与排行榜。

没有收藏数据时显示明确空状态，不能用累计历史收藏或模板使用次数代替近 30 天收藏人数。

## 14. 重要状态变化

| 场景 | 模板是否可见 | 是否允许发起 | 最终表现 |
| --- | --- | --- | --- |
| 组织模板停用 | 否 | 否 | 从全部、分类、常用和收藏中移除；恢复启用且仍可见后可重新出现 |
| 组织模板删除 | 否 | 否 | 入口失效，历史任务保留 |
| 用户不再命中部门或人员标签 | 否 | 否 | 从该用户的全部、分类、常用和收藏中移除；重新命中后可恢复 |
| 绑定 Skill 或知识库被停用、删除 | 是 | 是 | 可显示资源失效状态；执行到该资源时失败 |
| 用户没有绑定 Skill 或知识库权限 | 是 | 是 | 模板不授予权限；执行到该资源时失败 |
| 管理员失去已绑定资源权限 | 是 | 是 | 原绑定保留并显示无权限状态，不自动停用模板 |
| 个人模板绑定资源失效 | 仅本人可见 | 是 | 显示失效状态；执行到该资源时失败 |

## 15. 核心验收标准

1. 分类没有可见范围和启停字段，只能新增、编辑、删除和排序。
2. 组织模板可以选择组织全员，或者同时选择多个部门和多个人员标签。
3. 用户命中任意已选部门或人员标签即可看到模板；选择父部门时，其所有层级子部门成员均命中。
4. 模板可见范围不能直接选择具体人员。
5. 管理员能够为组织模板选择本人可见的全局内置 Skill、企业 Skill、个人 Skill 和知识库。
6. 单个模板可以同时绑定多个 Skill 和多个知识库，Skill 不超过 50 个，知识库不超过 50 个。
7. 普通用户没有绑定资源权限时，仍能看到、收藏并发送模板；模板不会因此向用户授予资源权限。
8. 已绑定资源被停用、删除或变为无权限后，模板仍保持原启用和可见状态，界面能够识别时显示失效原因；Skill 沿用现有执行链，知识库以写入会话的助手消息结束本轮，不显示内部错误。
9. “我的”支持用户自主创建、编辑、删除和使用个人模板；个人模板只能绑定当前用户可见的 Skill 和知识库。
10. 其他用户和租户管理员均不能查看或编辑某个用户的个人模板，个人模板不能发布或分享。
11. 首页不展示“猜你要用”，系统不读取历史对话自动生成模板。
12. 收藏列表和收藏数量只包含当前有效收藏；模板停用、删除或用户失去可见范围时不返回占位且不计数。
13. 用户可以查询和修改仅影响本人的常用统计窗口、最少使用次数和最多展示条数；未保存时使用默认值，覆盖至少 2 个自然日固定不变。
14. 收藏排行榜只统计有效组织模板，按最近 30 天内当前仍收藏且收藏用户仍可见的去重用户数排序，默认返回 Top 10。
15. 用户取消收藏后立即退出相应收藏计数；重新收藏时，同一用户在窗口内仍只计算一次。
16. 点击或填入模板不计使用，任务提交被接受才计使用；提交后因 Skill 或知识库失败仍计一次使用。
17. 模板关联期间每次有效发送分别计一次使用；统计允许少量重复或漏记，不能因模板状态或统计失败影响对话主功能。
18. 用户可以在发送前增删模板预置的 Skill 和知识库，执行时以最终选择结果为准；知识库权限、删除或停用错误以写入会话的助手消息返回，不显示内部错误。

## 16. 后续阶段边界

以下内容不阻塞本需求进入技术设计，但需要在设计或测试阶段落实：

- 资源选择器如何分页、搜索和展示不同来源；
- 失效资源在不同页面上的具体视觉样式；
- 收藏排行榜同分时的稳定排序规则；
- 模板、Skill 和知识库之间的具体接口与存储方式；
- 资源失效状态的刷新时效及失败降级方式。
