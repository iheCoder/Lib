# 候选冻结前的基线观察

已读取 r01 与 r02 各四轮实际输出。两次均讨论了正文内参数、使用受理点、尽力记录、常用明细聚合、动态窗口、自然日、先有效性过滤再截取、主要索引和成本增长。都保留局部讨论，没有输出最终设计文档。

缺口集中在排序：首轮给出列表版本与冲突选择，说明正文修改不改变排序版本。r01 第三轮又让空分类删除与成员变化通过分类记录协调，但仍未展示具体重排更新范围、对普通编辑的锁等待、写放大及其代价。不能把逻辑版本隔离当作物理竞争隔离。四轮未覆盖不等于后续不会覆盖；候选只试图使这种影响在机制选择时更早出现。

原拟增加的通用读写链提示暂不加入：本次基线已经出现较完整读写链，缺少再扩写的实证理由。候选只新增一段机制作用范围的判断原则，不包含常用、模板、分类、富文本等本题特有名词，不预设具体算法。
