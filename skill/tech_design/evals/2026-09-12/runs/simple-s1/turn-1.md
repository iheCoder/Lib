本功能允许项目所有者修改项目显示名称。下面按已经确认的规则整理技术设计，可作为后续实现依据。

系统由单个 Go 服务和 MySQL 组成，供内部后台每天使用几十次，没有外部依赖。名称去除首尾空白后，必须包含 1–50 个 Unicode 字符；不同项目可以同名。并发修改采用最后一次提交成功的结果。

数据直接保存在已有的 projects 表中：id 标识项目，owner_id 表示项目所有者，display_name 保存当前显示名称。修改名称只改变 display_name，项目身份和归属保持原样。这次功能无需增加新的业务对象或字段。

一次修改按以下过程执行：

1. **接收请求并识别用户。** 接口采用 `PATCH /projects/{projectID}/display-name`，请求体中的 `display_name` 表示新名称。项目 ID 来自路径，操作者身份来自服务端已验证的登录信息。客户端提供的用户 ID 不能作为授权依据；未登录时按现有登录机制拒绝请求。

2. **整理并校验名称。** 服务端先去除首尾空白，再检查字符数。Go 中按 Unicode 码点计数，中文字符不会按其 UTF-8 字节数重复计算；名称内部的空格保持原样。整理后的名称为空或超过 50 个字符，直接返回名称校验错误，不修改数据库。后续写入和返回都使用整理后的同一个名称。

3. **在现有事务中执行条件更新。** 更新条件同时包含项目 ID 和当前登录用户 ID，只允许修改该用户拥有的项目。权限约束直接放在更新语句中，避免仅依靠此前的一次查询决定是否允许写入。更新只设置 display_name，不覆盖项目的其他字段。

4. **判断更新结果，正确处理同名提交。** 数据库执行报错时进入事务失败处理。执行成功且确认匹配到项目时，继续提交事务。如果数据库报告影响行数为零，不能直接判断为不可操作：MySQL 的返回方式可能把“有权限，但名称本来就相同”也报告为零。此时在同一事务内，使用同样的项目 ID 和所有者条件做一次加锁的当前读取。能读到项目，说明这是合法的重复设置，可以成功；读不到项目，统一返回“项目不存在或当前用户不可操作”。这次读取用于区分结果，实际写入权限仍由更新条件保证。

5. **提交成功后返回结果。** 服务端只有在现有事务提交成功后，才返回成功以及修改后的 `display_name`。如果事务由上层统一管理，名称更新函数返回并不代表整个请求已经成功，响应仍须等待最终提交结果。后台界面收到成功响应后显示返回的名称；收到校验错误、不可操作或数据库失败时，显示对应错误，不提示保存成功。

项目不存在和非所有者操作使用相同的业务错误及对外响应，客户端无法通过这个接口区分两种情况。具体错误码、响应包装和登录失败格式沿用现有服务约定。

并发规则由数据库对同一项目行的更新串行化实现。比如两个请求分别把名称改为“项目甲”和“项目乙”：先取得该行更新锁的事务完成后，另一个事务才能继续修改。如果两个事务都成功提交，最终保存的是后提交的名称；如果后一个事务失败，则保留前一个已提交的结果。排序依据是数据库实际完成的顺序，与用户点击顺序或请求抵达顺序可能不同，这符合已经接受的并发规则。

每次成功响应表示该请求的名称已经提交，不保证它之后不会被另一笔合法修改覆盖。因此，一个请求返回“项目甲”时，另一个请求可能已经把当前名称改成“项目乙”。页面再次读取项目时，以数据库中的当前名称为准。

重复提交同一个名称应正常成功，不额外创建任何记录。如果两次重复请求之间已有别人通过同一所有者身份提交了新名称，后来的重复请求仍按一次普通修改执行，可能再次覆盖当前名称。这是既定并发规则的自然结果，客户端不应在用户不知情的情况下持续自动重试旧修改。

更新执行失败时，按现有事务管理方式回滚，不提交部分修改。如果数据库已经提交，但响应因连接中断没有到达客户端，客户端可能无法确认这次操作是否完成。此时不能显示保存成功，应提示结果未确认，并通过重新读取项目查看当前名称；再次提交仍遵循上述覆盖规则。

每次操作定位并更新一个项目，不随项目总数批量扫描或修改其他项目。通常只有一次更新，同名提交等零影响行数的情况增加一次确认读取。相同项目的并发修改会等待同一行上的事务，因此现有事务应及时完成，避免把与本次保存无关的耗时工作放进事务中。按每天几十次的使用量，无需引入缓存、队列或异步任务；这属于基于操作规模的设计判断，尚未执行性能测试。

以上系统前提来自已确认需求，尚未核查实际源码和表定义。实施时需核实两个常规存储条件：项目 ID 能通过已有主键或唯一索引定位单行，display_name 的编码和容量能够完整保存最多 50 个 Unicode 字符，包括补充平面字符。若现有列不满足这一条件，应调整列定义，保证通过应用校验的名称不会在写入时被截断或因编码不支持而丢失。
