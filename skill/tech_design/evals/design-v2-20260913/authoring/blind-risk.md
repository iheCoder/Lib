# 技术设计 Skill 拟改方向：独立前置风险盘点

本盘点只依据父任务提供的原始改进诉求，以及当前 `skill/tech_design/SKILL.md`。未读取历史评测、候选实现、具体题目或评分材料；以下是候选揭示前的预判，不是已观察到的候选缺陷。

## 最可能的错误与规则反作用

1. **正确性、业务操作身份和处理边界只写了名称，未落实到同一条执行过程。**
   最可能的遗漏是把“收到请求”当成可靠受理，把可靠受理当成业务完成；用每次请求的新编号识别业务操作，导致网络重试重复产生效果；或复用一个编号却忽略同一业务动作参数已经改变。判断时应沿响应丢失、进程中断、重复提交走完，检查保存的证据、调用方所见结果和副作用是否一致。新增规则的反作用是要求每个简单同步操作都建立操作表、持久队列和完整状态机，或者无依据承诺“恰好执行一次”。所需身份、持久化和可恢复承诺应来自当前操作的失败后果。

2. **“权威来源”变成对整个系统贴标签，事实仍互相冲突。**
   最可能的遗漏是说“数据库为准”就结束，却没有区分权限、外部执行结果、进度展示等具体事实；没有解释副本过期、外部调用超时或写入中断时由谁判断真相。判断时应看同一事实发生矛盾后具体读哪里、谁可以修改、未知时允许什么行为。新增规则的反作用是凭空增加一个中央事实库，或强行让所有事实共享同一个来源和一致性要求，造成双写或额外耦合。

3. **长任务的取消、取代和过载处理停留在状态变更，旧工作仍可造成效果。**
   最可能的遗漏是标记旧任务取消就认为旧结果不会写入，或接收新任务后忽略运行中的外部副作用；过载时只说排队，没有说明何时拒绝、已经受理的工作是否会丢失，以及用户如何得知。判断时应看新旧任务交错完成、队列积压和重启后的真实行为。新增规则的反作用是把“新任务取代旧任务”预设为所有长任务的业务规则，或为了低频本地任务引入调度平台；取代、共存、拒绝或合并必须先符合该业务的含义。

4. **事实、已定方案、假设与未决问题被整理成表，却未影响后续决策。**
   最可能的遗漏是用户纠正前提后仅更新局部回答，仍沿用被推翻的模型；把模型建议或推算升级成事实；把会推翻主方案的未决问题藏在文末。判断时应观察一次自然的前提修正能否让相关流程、模型与结论一起改变，以及已经明确授权的决定是否避免重复确认。新增规则的反作用是每轮维护庞大台账、固定字段和问题配额，导致真正的机制讨论被记录工作替代。需要的是结论一致与依据清楚，不是特定展示格式。

5. **Agent 边界写成“模型判断、代码执行”的口号，故障和恢复仍无人负责。**
   最可能的遗漏是没有说明哪些条件才调用模型、模型输出如何约束到允许的动作；工具超时后盲目重试非重复安全的副作用；修复动作引入第二次损害；批准后长时间暂停再继续时，权限、目标或输入已经变化；把工具输出中的文字当成新的授权。判断时应看一次不确定工具结果和一次暂停后条件变化，能否给出可执行的继续、核验或停止条件。新增规则的反作用是为普通程序强加 Agent 章节，或让一切工具调用都进入人工审批，阻塞已授权的常规工作；同时不能把确定性代码验证误说成能证明开放式模型判断必然正确。

6. **覆盖面扩大后，牺牲通俗表达、最小复杂度和需求范围。**
   最可能的遗漏是把上述方向当作强制清单，对与任务无关的问题逐项问用户；新增术语先于业务解释；边界推演扩成完整测试、监控和部署方案。判断时除复杂案例外，还应看简单且前提充分的任务是否直接进入必要机制、低影响未知是否能说明假设后继续、没有真实分叉时是否避免制造方案。新增规则的反作用是“少问、简化”被解释为跳过关键正确性取舍，或者为了保持短小只列关键词而省掉读者理解一次操作所需的过程。合格的克制应同时保留必要因果关系和真实风险处理。

## 哪些观察不能证明能力提高

- 输出出现更多“幂等、可靠受理、权威来源、信任边界”等词，章节更多或文档更长，只证明表面覆盖增加；没有完整的执行过程和失败后果，不能证明设计更正确。
- 候选在作者看过的题目上覆盖了预设要点，不能证明能迁移到未见需求，也不能排除按题写规则；同一上下文生成或复核产生的赞同不是独立能力证据。
- 仅检查最终文档，不能证明多轮互动能维护已定结论、响应前提变化或避免重复提问；这些需要实际交互轨迹。
- 问题数量更少、回答更短或架构更简单，单独看不能证明改善；可能来自省略真正改变方案的未知或失败边界。
- 在复杂任务上补全风险，不能证明没有过度设计的回归；还需要观察简单任务和无 Agent 的任务是否仍保持恰当范围。
- 文字推演逻辑自洽，只能支持设计层面的可解释性；不能作为吞吐量、故障恢复成功率、外部服务承诺或生产正确性的实测证明。单次成功案例也不能证明稳定提升。

后续揭示候选和题目时，应保留本文件作为前置预判，另行记录观察、支持或反驳证据，以及仍不能判断的部分，避免将已看见的表现倒写成原先就预测到的风险。
