# 分享视频下载器

`tk_downloader` 是一个用 Go 实现的公开视频下载工具，同时提供本地网页端和命令行。它接收 App 复制出的完整分享文案或作品链接，从移动分享页解析作品信息，并下载公开链路能够提供的最高可用、无平台水印、无引流尾帧的视频内容流。

程序不依赖第三方解析网站，不需要登录，也没有内置浏览器或 JavaScript 签名实现。当前目标是可靠完成单个公开视频的下载闭环，而不是覆盖图集、直播、账号批量下载等所有内容形态。

> 详细的设计推导、数据流、安全边界和关键源码说明请阅读 [ARCHITECTURE.md](./ARCHITECTURE.md)。

## 使用前提

- Go 1.23 或更高版本。
- 当前网络可以访问分享页和视频 CDN。
- 作品无需登录即可公开访问。
- 仅下载自己拥有或已获授权保存的内容，并遵守平台条款及所在地法律。

## 网页端

在仓库根目录启动本地网页服务：

```bash
go run ./utils/video/tk_downloader -web
```

终端出现下面的提示后，打开 [http://127.0.0.1:17846](http://127.0.0.1:17846)：

```text
网页端已启动: http://127.0.0.1:17846
按 Ctrl+C 停止服务
```

将完整分享文本或作品链接粘贴到输入框，点击“解析视频”，确认作者和标题后点击“下载原片”。浏览器会直接保存 MP4，服务端不会先在项目目录生成视频副本。

需要修改监听地址时使用：

```bash
go run ./utils/video/tk_downloader -web -addr 127.0.0.1:18080
```

默认地址只监听本机回环接口。解析成功后生成的下载地址有效十分钟，过期后需要重新解析。

## 命令行

传入完整分享文本并指定保存目录：

```bash
go run ./utils/video/tk_downloader \
  -o ./utils/video/tk_downloader/downloads \
  '2.07 复制打开，看看作品 https://v.douyin.com/example/'
```

也可以只传作品链接。省略 `-o` 时，文件保存到当前目录：

```bash
go run ./utils/video/tk_downloader 'https://v.douyin.com/example/'
```

下载成功后会输出作品元数据和实际文件路径。同名文件不会被覆盖，程序会自动添加 `(1)`、`(2)` 等数字后缀。按 `Ctrl+C` 可以取消页面请求或视频下载；取消或网络失败时，未完成的临时文件会被清理。

## 构建独立程序

```bash
go build -o ./bin/tk-downloader ./utils/video/tk_downloader
./bin/tk-downloader -o ./downloads '粘贴完整分享文案'
```

查看所有参数：

```bash
./bin/tk-downloader -h
```

## 支持范围

当前支持：

- 带有 `v.douyin.com` 短链接的完整分享文案。
- `douyin.com/video/{作品ID}` 形式的作品链接。
- 无需登录即可访问的单个视频作品。
- 自动解析作者、标题、作品 ID 和播放地址。
- 流式下载、中文文件名清理和同名文件保护。
- 网页端与命令行共用同一套解析及媒体校验逻辑。

当前不支持：

- 私密、好友可见或必须登录的作品。
- 图集、直播、合集和批量账号下载。
- 验证码自动处理及登录 Cookie 注入。
- 下载进度、断点续传和多清晰度选择。
- 创作者上传母版。公开分享链路可能只开放转码后的最高可用版本。

## 基本技术说明

程序使用移动端 User-Agent 请求服务端渲染的分享页，从页面内的 `window._ROUTER_DATA` 提取最小作品信息。解析器把 `/aweme/v1/playwm/` 分享播放入口转换为 `/aweme/v1/play/` 原内容入口，并请求 `2160p` 偏好档位；最终分辨率仍由媒体服务器按作品公开可用规格决定。

网页端静态资源通过 `go:embed` 编译进可执行文件。页面先调用 `POST /api/resolve` 获取作品信息和短期下载票据，再通过 `GET /api/download/{ticket}` 让本地服务流式转发媒体。浏览器不会收到上游媒体地址。

所有出站地址及每一次重定向都会经过 HTTPS 域名白名单校验。网页端还使用同源检查、严格 CSP、请求体上限和随机票据缩小本地服务的攻击面。

## QA 与验证

运行自动化测试和静态检查：

```bash
go test ./utils/video/tk_downloader
go vet ./utils/video/tk_downloader
```

测试使用本地 HTTP 服务替代真实网络，覆盖：

- 分享文案提取和仿冒域名拒绝。
- 短链重定向、移动端请求头及 `_ROUTER_DATA` 映射。
- `playwm` 到 `play` 的安全转换。
- 媒体重定向、类型校验和流式保存。
- 临时文件清理及同名文件不覆盖。
- 网页同源限制、短期票据、附件响应和流式代理。
- 嵌入页面的安全响应头及可机械验证的设计约束。

真实链接仍应在发布前人工验证一次，因为页面结构、风控策略和 CDN 行为属于程序控制范围之外的外部依赖。本项目示例作品曾验证得到 H.264、1080×1920、约 4.93 秒的无水印内容流；这个结果只说明当次公开链路的返回规格，不构成对其他作品清晰度的承诺。

## 故障排查

`没有找到受支持的 HTTPS 分享链接` 表示输入中没有完整链接，或者链接域名不在允许范围内。建议重新复制分享文案，并在命令行中用引号包住整段文本。

`返回了风控校验页` 表示当前 IP、访问频率或页面策略触发了校验。程序不会自动绕过验证码，可以稍后重试，并先确认同一链接能否在普通浏览器中无登录打开。

`作品播放地址不在受信任的媒体域名下` 表示页面出现了尚未确认的媒体域名或异常数据。应人工验证新域名的归属后再更新白名单，不要直接移除地址校验。

`媒体服务器返回了非视频内容` 表示播放入口返回了 HTML、JSON 或其他错误响应，而不是视频字节流。常见原因包括作品权限变化、媒体地址失效或上游风控。

作品页面声明的画布尺寸不等于公开分享链路一定提供同规格文件。程序请求最高偏好档位，但不能从较低清晰度的公开转码文件恢复创作者上传母版。
